Student Management System (Java JDBC)

A console-based Student Management System developed using Java, JDBC, and MySQL.

## Features

- Insert Student
- Display Students
- Update Student
- Delete Student
- Search Student by ID

## Technologies Used

- Java
- JDBC
- MySQL
- VS Code

## Project Structure

student_main/
├── Main.java
└── students.java

## Database

```sql
CREATE TABLE students(
    id INT PRIMARY KEY,
    Name VARCHAR(50),
    Department VARCHAR(50),
    marks INT
);
```
